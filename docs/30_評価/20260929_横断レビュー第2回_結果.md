# 横断レビュー第2回（コードの正しさ・検査の穴・文書間整合）2026-09-29

**位置づけ**: 前回（[コードと文書の横断レビュー](20260929_コードと文書の横断レビュー_結果.md)＝要件・再現性・依存関係）に続く第2回。
今回は **①道具スクリプトの正しさ ②検査そのものの穴 ③文書どうし・文書対実測値の整合** を、
文書班とコード班の**2系統の独立レビュー**で洗い、全指摘を一次情報と突き合わせてから直した。

**結論**:
- **36件の不一致・欠陥が出た**（高5・中13・低18）。
- 最重は **(a) 比較実験スクリプトの対照条件が既定値変更で汚染され、記録値を再現できない**、
  **(b) 公開される2スクリプトが社内限りの検査器を import しており、公開リポジトリでは ImportError で即死**、
  **(c) 公開安全検査が「対象0件」でも合格を返す**（0件マッチ合格の型）。
- **全件を修正または訂正し、フルチェーン（数値台帳・提出物検査・公開安全検査・比較実験の実機回帰）で確認した。**

### 1-1. なぜ #1〜#3 が重いか

3件とも**「手元では絶対に露見しない」型**である（リスク R-33 と R-34 の合流点）。
- #1 は**再実行して初めて**分かる——比較の結論（画角が効く）を第三者が検証できない状態だった。
- #2 は**公開側でだけ**壊れる——採点者が参考に動かした瞬間に ImportError。
- #3 は**検査が壊れたときだけ**現れる——「全項目 OK」の顔をして何も見ていない。

## 2. 意思決定（詳細は `docs/03_実施方針.md`〈社内限り〉の DEC-55〜58）

| **DEC-57 / C-41** | 比較実験の各条件は共有既定値に頼らず明示する（設計原則4の対偶） |
| **DEC-58 / C-27改** | 数値台帳の検査対象に公開 README を加える（手書きが残る場所は3つ） |
