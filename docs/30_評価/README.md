# 30_評価 — 確定した評価結果の置き場

**ここが数値の正。** 他の文書には数値を写さず、このフォルダへリンクする。

## 置くもの

| ファイル名の形 | 内容 |
|---|---|
| `YYYYMMDD_<条件名>_結果.md` | 1回の評価ランの確定結果（指標・失敗モード内訳・検算結果） |
| `YYYYMMDD_アブレーション.md` | 条件間の比較（C0〜C3） |

## 書く内容（最低限）

1. **実行条件**: 使用した `run_id`、設定ファイル、乱数種、エピソード数
2. **指標**: M-1〜M-5 を**分子／分母の形**で
3. **失敗モード内訳**: F-1〜F-9 の件数。`成功数 + Σ失敗 == 総数` の**検算結果を明記**
4. **解釈**: 何が言えて、何が言えないか。**言えないことを明記する**

## 書かないこと

- 途中経過・試行錯誤（それは `experiments/` に置く）
- 「おそらく」「たぶん」で始まる推測（根拠がないものは書かない）
- 非有意な差を「同等」「改善」と読み替えた記述

指標と失敗モードの定義: [docs/20_設計/02_評価設計.md](../20_設計/02_評価設計.md)
