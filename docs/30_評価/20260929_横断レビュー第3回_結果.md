# コード・文書・課題要件の横断レビュー（第3回、2026-09-29）

**位置づけ**: **提出動画の構成・尺・容量の正**（[20260929_提出物の可搬性検証_結果.md §6-1](20260929_提出物の可搬性検証_結果.md) の該当値を置き換える）。
**きっかけ**: コード一式・文書一式・課題要件の3観点での網羅レビュー依頼。
**やり方**: 機械チェックを走らせるだけでなく、**提出動画のフレームを実際に抜き出して画素で比べた**。

**結論**:
- **是正が「コードに入った」ことと「提出物に届いた」ことは別である。**
  `src/recording.py` の焼き込み文字の是正（DEC-38）は**コードには入っていたが、提出動画には入っていなかった**。
  焼き込み文字は**素材の中**にあるため、**録り直さない限り提出物には届かない**。
- **機械チェックは6件すべてに無言だった。** 第1回・第2回と同じ構図である。
- 再発を止める仕掛けを機械側へ入れた（**素材の焼き込み文字を画素で検査**・**区間長と字幕を実測から導出**）。

### 1-1. 問題1が「機械には見えない」理由

| 層 | 何が直ったか | 提出動画へ届くか |
|---|---|:-:|
| `scripts/build_submission_video.py` の字幕（`drawtext box=1`） | 下地が付いた | **届く**（組み立て時に描く） |
| **`src/recording.py` の左上バナー**（`_draw_overlay`） | 下地が付いた | **届かない**——**素材に焼き込まれているため** |

∴ **同じ「下地を付ける」という是正でも、片方だけが提出物に反映されていた。**
そして**文書には「是正後：下地付きで判読可」とだけ書かれていた**ので、
文書を読む限り両方が直ったように読めた。

> **一般化**: **成果物に焼き込まれるものは、コードを直しても作り直すまで変わらない。**
> `git` の差分にも機械チェックにも出ないので、**実物を見る以外に検出手段がない。**
> ∴ **実物を見る行為そのものを機械にやらせる**（DEC-61）。

## 2. 実測

### 2-1. 焼き込み文字の下地の有無（画素で判定）

左上バナー領域の平均輝度を、**その真下の同じ列**と比べた比率。
下地は元の明るさを 0.25 倍にするので、下地があれば比は 1 を大きく下回る。

| 素材 | 記録日時 | 比（4点の実測） | 下地 |
|---|---|---|:-:|
| `20260927_212018_c4_master`（**提出動画が使っていた**） | 09-27 21:21 | 1.149 / 1.035 / 1.032 / 0.929 | **無し** |
| `20260929_100155_c4_master_v2` | 09-29 10:02 | 0.674 / 0.628 / 0.611 / 0.510 | **有り** |

**2群は重なっていない。** 境を 0.85 に置けば機械で判定できる。

### 2-2. 通し区間 47.0 秒が指していた範囲

| エピソード | 開始 | 終了 | 結果 |
|---|---:|---:|:-:|
| ep0 | 0.0 | 12.1 | 失敗 |
| ep1 | 12.1 | 19.7 | 失敗 |
| ep2 | 19.7 | 34.3 | 失敗 |
| ep3 | 34.3 | 46.9 | 失敗 |
| **ep4** | **47.0** | 67.0 | **成功** |

**`[0.0, 47.0]` は ep0–ep3、すなわち失敗回だけである。**
字幕は「5エピソードを通しで」と言っていたが、**映っていたのは4エピソードで、
しかも唯一の成功回が入っていなかった。**

> `build_submission_video.py` の説明文には
> 「**素材の切り出し位置は `summary.json` の `timeline` から取る（目分量で切らない）**」
> と書いてあった。**この1行だけが自分の宣言を破っていた。**

## 3. 意思決定

| ID | 決めたこと | 理由 |
|---|---|---|
| **DEC-61** | **提出動画を組む前に、素材の焼き込み文字に下地があるかを画素で検査して止める** | 更新時刻では判定しない——**複製やチェックアウトで動く**。見るべきは実物である |
| **DEC-62** | **区間の尺も字幕も、素材の `timeline` と `events.jsonl` から導出する。手打ちしない** | 手打ちは**素材を替えた瞬間に嘘になる**。実際に47秒と「5エピソード」の両方が嘘になっていた |
| **DEC-63** | **提出動画の素材は `20260929_100155_c4_master_v2` とする** | DEC-38 反映済みで、設定は旧素材と `tag` 以外完全一致（∴ **結果の数値は変わらない**） |
| **DEC-64** | **動画の字幕に素材 run の成功率を書かない** | DEC-40 の適用範囲を字幕にも広げる。素材は5エピソード、図は20エピソード——**同じ指標が2つの値を持つ** |
| **DEC-65** | **失敗区間はエピソードの「末尾」を切り出す** | 手順は順に実行されるので**失敗は後半で起きる**。先頭を切ると、字幕が言う失敗が画面に出ないまま終わる |

## 3-1. 追加したリスクと制約

| ID | 内容 |
|---|---|
| **R-35** | **成果物に焼き込まれる是正は、作り直すまで提出物へ届かない。** git 差分にも機械チェックにも出ない |
| **R-36** | **手打ちした区間長・字幕は、素材を差し替えた瞬間に事実と食い違う** |

| **C-44** | **動画の字幕に素材 run の指標を書かない**（DEC-40 / DEC-64） |
