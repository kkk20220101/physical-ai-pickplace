## 5. 公開前確認（G-C）

### 方式を変えた（意思決定 DEC-27）

最初は「出してはいけないものを挙げる」除外方式で作った。実行すると**12ファイルが引っかかった**が、
中身を見ると大半は**「業務資産を使わない」と書いている制約文**だった。

しかし、ここで許可リストへ足して回るのは誤りである。

> **除外方式では、新しく作ったファイルが既定で公開される。**
> 書き忘れが**そのまま公開事故**になる。
> **許可方式なら、書き忘れは「公開されない」側へ倒れる。**

∴ `configs/publish_manifest.txt` に**出すものだけ**を列挙する方式へ変更した。

### 公開するもの / しないもの

| | 対象 | 理由 |
|---|---|---|
| **公開する** | `src/` `scripts/` `configs/` `experiments/` | コード一式（要件 R-05） |
| **公開する** | `README_public.md` `docs/20_設計/` `docs/30_評価/` `docs/40_報告/` | 設計と結果。**再現性の根拠** |
| **公開しない** | `docs/_原本/` | 講師配布資料。**再配布の可否が不明** |
| **公開しない** | `docs/02_要件定義.md` `docs/03_実施方針.md` | 業務案件名を制約として含む |
| **公開しない** | `docs/10_調査/` | サーバの実パス・社内プロキシの情報を含む |
| **公開しない** | `tasks/` | 個人の進行管理。公開する意味がない |
| **公開しない** | `outputs/` `data/` | 中間生成物・容量 |

## 6. 言えること／言えないこと

| | 内容 |
|---|---|
| **言える** | 動画・レポート原稿・図・公開用リポジトリの中身が揃った |
| **言える** | 動画は要件（MP4・1〜5分・200MB以下・成功エピソードを含む）を**機械的に確認済み** |
| **言える** | 公開対象に業務案件名・資格情報は**1件も無い**（機械検査） |
| **言えない** | **レポートが評価者に伝わるか**（読み手の評価は測れない） |
| **言えない** | 講師配布資料（`docs/_原本/`）を公開してよいか。**判断できないので出さない**方に倒した |
| **言えない** | 動画の尺配分が最適か（1本しか作っていない） |
