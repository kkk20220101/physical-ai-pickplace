## レポートの構成（案）

要項で求められているのは「概要・目的・工夫した点」の3点。加点4観点に対応させて構成する。

| 節 | 内容 | 対応する加点観点 |
|---|---|---|
| 1. 概要 | 何を作ったか（1段落＋システム図1枚） | 表現力 |
| 2. 目的 | なぜこのタスクを選んだか。現実のどの課題に対応するか | 実用性 |
| 3. システム構成 | 知覚・計画・制御の3層。図で説明 | 技術力 |
| 4. 工夫した点 | 設計判断とその理由。**却下した案も書く** | 創造性・技術力 |
| 5. 評価結果 | 成功率・失敗モード内訳・アブレーション | 技術力・実用性 |
| 6. 限界と今後 | **できなかったことを正直に書く** | 実用性 |

> **4節が加点の主戦場。** 「何をしたか」ではなく「なぜそうしたか」を書く。

## 動画の構成（案・目標4分）

| # | 場面 | 尺 | 内容 |
|:-:|---|:-:|---|
| 1 | タイトル | 10秒 | 課題名・タスク名・（倍速の場合は**倍率を明記**） |
| 2 | 問題設定 | 30秒 | 何をさせたいか。図で説明 |
| 3 | システム構成 | 40秒 | 3層の流れをアニメーションで |
| 4 | **実行の様子** | 120秒 | **本体。成功するエピソードを必ず含める** |
| 5 | 認識結果の可視化 | 30秒 | AIが何をどう見ているか |
| 6 | 評価結果 | 30秒 | 成功率・失敗モードのグラフ |
| 7 | まとめ | 20秒 | 限界と今後 |

合計 4分20秒 → 編集で 4分以内に収める（要件: 1分〜5分）。

### 動画の注意点

- **音声なしでも理解できるようにテロップを入れる**（視聴環境が不明なため）
- **倍速を使う場合は画面上に常時表示**し、レポートにも記載する（U-05: 過剰側に倒す）
- 解像度とビットレートは、**Zip 200MB 以内**に収まる値を先に決める
