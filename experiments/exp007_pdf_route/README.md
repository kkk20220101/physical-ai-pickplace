# exp007 — PDF 変換経路の実測比較

**目的**: レポート原稿を PDF にする経路を、**目視でなく数字で**選ぶ。
**結論**: **LibreOffice 経路を採用**（DEC-30）。容量が 0.70MB 対 50.2MB（72分の1）で決着した
（`out/result.json` が一次情報。旧記載 0.52MB は出典が現存せず 2026-09-29 に訂正）。

## 実行

```bash
python experiments/exp007_pdf_route/probe_pdf_routes.py
```

`out/result.json` に両経路の検査結果が出る。**`out/` は `.gitignore` 済み**
（50MB の比較用 PDF が公開対象に紛れ込んだため＝DEC-32）。

## 判定に使った3つの機械検査

1. 抽出テキストに日本語が入っているか（**文字として**入っているか）
2. 日本語スパンが CJK フォントで描かれているか（**豆腐＝非CJKフォントへの代替**の検出）
3. 図が6枚とも埋め込まれているか

> **この3つでは足りなかった。** 図は「埋め込まれている」だけで**紙面からはみ出していた**。
> 本番スクリプト側には**配置矩形がページに収まっているか**の検査を足した（R-24）。
