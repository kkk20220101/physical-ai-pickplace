**実施日**: 2026-09-27
**確定結果の置き場**: [docs/30_評価/20260927_L1ベースライン_結果.md §6-1](../../docs/30_評価/20260927_L1ベースライン_結果.md)

## 仮説（実験前に書いた）

把持が失敗するのは**把持点の高さが合っていない**ためであり、物体ごとに z の補正値を
調整すれば、どの物体も安定して持ち上げられるようになる。

## 条件

| 項目 | 値 |
|---|---|
| 物体 | Milk / Bread / Cereal / Can |
| 把持点の z 補正 | -0.01, 0.00, +0.01, +0.02 [m] |
| シード | 0〜4（5個） |
| 試行数 | 4物体 × 4水準 × 5シード = **80** |
| 成功の定義 | 持ち上げ量 ≥ 0.05 m（評価設計 F-5 の定義と同じ） |
| 各試行 | `prim.reset()` で初期化。**前の試行の影響を持ち越さない** |

## 実行

```bash
MUJOCO_GL=egl python scripts/sweep_grasp.py --seeds 5
```

## 結果

| 物体 \ z補正 | -0.01 | +0.00 | +0.01 | +0.02 |
|---|:-:|:-:|:-:|:-:|
| Milk | 2/5 | 3/5 | 3/5 | **4/5** |
| Bread | **4/5** | 4/5 | 2/5 | 0/5 |
| Cereal | 2/5 | 2/5 | 2/5 | 2/5 |
| Can | **5/5** | 5/5 | 5/5 | 5/5 |

持ち上げ量の中央値 [m]:

| 物体 | -0.01 | +0.00 | +0.01 | +0.02 |
|---|:-:|:-:|:-:|:-:|
| Milk | -0.027 | 0.186 | 0.184 | 0.188 |
| Bread | 0.237 | 0.226 | 0.024 | -0.003 |
| **Cereal** | **-0.011** | **-0.011** | **-0.011** | **-0.011** |
| Can | 0.229 | 0.229 | 0.219 | 0.210 |

## 結論

**仮説は半分だけ正しかった。**

- Milk / Bread は補正値によって明確に成否が変わる（Bread は +0.02 で 0/5、-0.01 で 4/5）。
  **∴ 物体ごとの補正値は必要であり、有効。**
- **Cereal はどの水準でも 2/5、持ち上げ量の中央値が全水準で -0.011 m と完全に同一。**
  これは「掴めずに下へ押している」状態であり、**高さの問題ではない**。
  Cereal の horizontal_radius は 0.040（幅 8cm）で、Panda のグリッパ開口幅とほぼ同じ。
  **∴ 幾何的な限界であり、補正では解決しない。**

## 言えないこと

- 5シードでの 4/5 と 3/5 の差は**偶然の範囲**。順位付けの根拠にしない。
  採用値は「明確に悪い水準を外す」ためのものであり、最適値の主張ではない。
- この結果は**単体試行**のもの。連続タスクでの成功率とは別物
  （実際 Can は単体 5/5 → 連続 5/10 に落ちた）。
