# exp008 — MolmoAct 実現可能性スパイク

**この実験が答える問いは2つだけ。**

1. **この環境で MolmoAct-7B-D をロードして推論できるか**
2. **1判断あたり何Hz出るか**（サーベイ資料の判定基準③「計画層 10Hz 以上」に届くか）

**採否を決める実験ではない。** 成功率の比較（H1）は**やらない**——
行動空間の対応付けに時間が要り、締切内で安全に終わらないため。

## なぜ環境を分けるか

MolmoAct のモデルカードは **`transformers==4.52`** を要求する。
本課題の実行環境は **transformers 5.5.4** であり、**そこへ 4.52 を入れると
検証済みの提出物パイプライン（OWLv2・Qwen2.5）が壊れる。**

∴ `parc-finals` を複製した専用環境 `molmoact` を作り、**そこだけで動かす**（DEC-59 / C-42）。

> **既存環境を触らないことを最優先にした。**
> 出力先も `outputs/molmoact_spike/` に限定し、**提出物には一切触れない。**

## 実行

```bash
# 隔離環境で実行する（既存環境では動かない。conda 環境名は molmoact）
conda run -n molmoact python \
    experiments/exp008_molmoact_feasibility/probe_molmoact.py --trials 5
```

**出力**: `outputs/molmoact_spike/result.json`

## 記録する値

| キー | 意味 |
|---|---|
| `結論` | 可／不可（不可なら例外をそのまま残す） |
| `ロード秒` / `パラメータ数` | 実際に載ったか |
| `レイテンシ秒_中央値` | 暖機1回を除いた中央値 |
| `計画層Hz_実測` | 1 ÷ 中央値 |
| `判定基準3_計画10Hz` | **達成／未達** |
| `必要な高速化倍率` | 10Hz に届かせるのに何倍要るか |
| `観測画像の由来` | robosuite 実シーンか合成画像か（**由来を曖昧にしない**） |

## 注意

- **`transformers==4.52.0` は PyPI 上で yanked されている。** 再現時は同じ警告が出る。
- robosuite はこの環境に無いため、**観測画像は同解像度の合成画像へ自動で退避する**。
  **速度は絵の中身に依存しない**ので問いには答えられるが、**由来は必ず記録する。**

## 結果（2026-09-29 確定）

**問い1（ロードして推論できるか）＝未達。** 独立した6回の試行すべてで
`from_pretrained` が完了せず、`outputs/molmoact_spike/result.json` は生成されなかった。
共通して「チェックポイント読込み 100%」表示の直後からログ出力が無いまま CPU 上で
長時間の計算が続き、常駐メモリ（RSS）が約32GBで頭打ちになる一方、GPU メモリ使用量は
初期状態から実質的に変化しなかった（重みの GPU 配置に至っていない）。
スレッド数固定・タイムアウト無しの29分監視でも同じ頭打ちに帰着したため、
**問い2（Hz実測）はこの環境・この期間内では答えられないと判断し、打ち切った。**
**ダミー値・推定値は記録していない。**
原因はコード調査（カスタム実装に meta device 対応の記述が無い）までの推測に留め、断定はしていない
（実行時スタックトレースの取得が権限制約で行えなかったため）。
