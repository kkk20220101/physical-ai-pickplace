# exp006 実行順が成功率に与える影響

**実施日**: 2026-09-27
**確定結果の置き場**: [docs/30_評価/20260927_言語計画層_結果.md §4-3](../../docs/30_評価/20260927_言語計画層_結果.md)

---

## なぜこの実験をしたか

全層AI（C4）を測ったら **29/60** だった。知覚だけAIの C3 は **41/60**。
「言語モデルを入れると12手順落ちる」と書きそうになったが、**出力を見ると計画の中身は同一**だった。

| 条件 | 計画の中身 | 実行順 |
|---|---|---|
| C3（固定ルール） | Milk→左 / Can→左 / Bread→右 | Milk, Can, Bread |
| C4（言語モデル） | **同一** | **Can, Milk, Bread** |

> **違うのは順番だけ。** この状態で「言語モデルが劣る」と結論づけるのは**交絡の見落とし**である。

## 仮説（実験前に書いた）

C4 の低下は言語モデルの計画能力ではなく、**実行順**だけで説明できる。

## 条件

| 項目 | 値 |
|---|---|
| **計画層は使わない** | 手順を直接与える（`RunConfig.explicit_plan`） |
| 知覚 | 推論（視線交点）、向きも推論 ＝ C3/C4 と同じ |
| エピソード数 | 20／順（実験前に決めた） |
| 初期配置 | 順の間で完全一致 |
| 変える要素 | **実行順だけ** |

## 結果

| 実行順 | タスク成功 | 手順成功 | 同定 | 主な失敗 |
|---|:-:|:-:|:-:|---|
| **順A** Milk→Can→Bread | **6/20** | **41/60** | 53/60 | F-5(10) F-3(7) F-7(2) |
| 順B Can→Milk→Bread | 2/20 | **29/60** | 49/60 | F-5(19) F-3(10) F-7(2) |
| 順C Bread→Milk→Can | 4/20 | 34/60 | 53/60 | F-5(14) F-3(7) F-7(5) |

**順B は C4 の初回測定（2/20・29/60・F-5(19) F-3(10) F-7(2)）と数値が完全に一致した。**

## 結論

**仮説は正しかった。**

1. C4 の低下は**実行順だけで完全に説明できる**。言語モデルの計画能力とは無関係。
2. **実行順だけで手順成功が 29〜41/60 まで動く（12手順）。**
   これは**真値をAIに置き換えたコスト（45→41、4手順）の3倍**である。
3. 順番を基準順へ揃えたところ、C4 は **41/60**（C3 と同一）に戻った。

## この実験の教訓

> **同じ「12手順の差」でも、原因が計画の中身か実行順かで結論が正反対になる。**
> 出力を並べて見比べていなければ、
> **「言語モデルは性能を下げる」という誤った結論**を提出物に書いていた。
>
> **差が出たら、まず「何が違っているか」を全部並べる。**

## 言えないこと

- **なぜ順Aが良いのか**は確かめていない。機構は未解明（S-11）。
  背の高い牛乳を先に退かすと残りが見やすくなる、等の仮説は立つが**測っていない**。
- 3つの順しか試していない。全6通りのうち3通りである。
- 20エピソードでの 34/60 と 41/60 の差（7手順）は、順Aと順Cの優劣を強く主張できる数ではない。
  **強く言えるのは 41/60 対 29/60（12手順）のほう。**
