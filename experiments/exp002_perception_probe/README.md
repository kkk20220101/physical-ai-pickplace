# exp002 知覚モデルの選定

**実施日**: 2026-09-27
**確定結果の置き場**: [docs/30_評価/20260927_知覚AI_アブレーション結果.md](../../docs/30_評価/20260927_知覚AI_アブレーション結果.md)
（**数値の正はそちら**。ここには過程と、遠回りした事実を残す）

---

## 仮説（実験前に書いた）

オープン語彙の物体検出モデル（OWL-ViT）に「牛乳パック」「缶」のような**意味語**を投げれば、
シミュレータの画像でも4物体を区別でき、深度画像と組み合わせれば把持に使える精度の3D位置が得られる。

## 条件

| 項目 | 値 |
|---|---|
| 画像 | robosuite `PickPlace` の `agentview`、512×512 |
| シーン数 | 3〜5（シードで変える） |
| 正解の判定 | 検出枠の中心が真値の投影位置から45画素以内、かつ最も近い物体が自分自身 |

## 経過

### 第1段: OWL-ViT + 全体画像 + 意味語 → **ほぼ全滅**

```
Milk 0/3   Bread 0/3   Cereal 2/3   Can 3/3
```

「a carton of milk」「a loaf of bread」が1回も当たらない。

### 第2段: 語のスイープ（16語 × 3シーン）→ **遠回りだった**

見た目に基づく語（`a white box`, `a brown object` 等）を含めて広く試した。

| 語 | 当たった先 |
|---|---|
| a soda can / a red can / a red cylinder | **検出なし** |
| a carton of milk / a white carton | **検出なし** |
| a cereal box | Cereal 2/3 |
| a tall red box | **Can 3/3**（語と実物が食い違っている） |
| a small brown box | Bread 2/3 |

**どの語も安定しない。** `a tall red box` が缶に当たるなど、語と対象の対応が崩れている。

> **ここで「語を工夫する」方向に行きかけたが、これは誤りだった。**
> 語と対象の対応が崩れているのは、**モデルが画像をきちんと見られていない**ということであり、
> 語の問題ではない。

### 第3段: モデルと画角を変える → **解決**

**語は第1段のまま**にして、モデル（OWL-ViT / OWLv2）と画角（全体 / 卓上切り出し）だけを動かした。

| 条件 | 同定 |
|---|---|
| OWL-ViT + 全体 | 5/20 (25%) |
| OWL-ViT + 切り出し | 8/20 (40%) |
| OWLv2 + 全体 | 11/20 (55%) |
| **OWLv2 + 切り出し** | **18/20 (90%)、取り違え0件** |

## 結論

**仮説は「意味語で区別できる」という点で正しく、「OWL-ViT と深度で足りる」という点で誤りだった。**

1. **意味語はそのままで良かった。** 語を見た目ベースに変える必要は無かった。
2. 効いたのは **モデルの規模／学習方法** と **対象が画面に占める大きさ**。
3. 深度画像から位置を取ると**系統的な偏り**が出る（→ exp003 で交点法に変更）。

## 遠回りから得た教訓

> **語が当たらないとき、まず語を疑ってはいけない。**
> 「ある語が別の物体に当たる」のは対応関係の崩壊であり、**入力かモデルの問題**である。
> 語のスイープに1ラウンド費やしたが、**モデルと画角を変えたら同じ語で90%になった**。

## 言えないこと

- 3〜5シーンでの 2/3 と 3/3 の差は偶然の範囲。**順位付けの根拠にしない。**
- 他のシーン・他の物体で同じ結論になるかは確かめていない。
