# experiments — 試行錯誤の記録

**書き捨ててよい場所。** 確定した数値は `docs/30_評価/` へ、確定した判断は `docs/03_実施方針.md` の
意思決定ログへ移す。ここには過程を残す。

## 使い方

1実験につき1フォルダを作る。

```
experiments/
└── expNNN_<短いテーマ>/
    ├── README.md      ← 仮説・条件・結果・結論
    ├── run.sh         ← 実行コマンド（そのまま再実行できる形で）
    └── (出力への参照)  ← 実体は outputs/<run_id>/ に置き、ここにはパスだけ書く
```

## README.md に書くこと

| 節 | 内容 |
|---|---|
| 仮説 | 何が起きると予想したか。**実験前に書く** |
| 条件 | 設定ファイル・乱数種・エピソード数・使用した環境 |
| 結果 | 数値（分子／分母の形）。**予想と違った場合もそのまま書く** |
| 結論 | 何が言えて、何が言えないか |
| 次 | この結果を受けて何をするか |

## やってはいけないこと

- 結果を見てから仮説を書き直す
- 都合のよい試行数・条件を後から選ぶ
- ここの数値を `docs/` へ写す（リンクで参照する）
