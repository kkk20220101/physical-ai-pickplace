# exp003 アブレーション（何が効いているか）

**実施日**: 2026-09-27
**確定結果の置き場**: [docs/30_評価/20260927_知覚AI_アブレーション結果.md §5](../../docs/30_評価/20260927_知覚AI_アブレーション結果.md)

## 仮説（実験前に書いた）

知覚を真値からAIの推論に置き換えると成功率は下がるが、**下がり幅は小さい**。
把持姿勢の向き合わせは、以前 2/12 → 9/15 の差を出したので**今も大きく効く**。

## 条件

| 項目 | 値 |
|---|---|
| エピソード数 | **20 / 条件**（実装前に決めた。結果を見て増減していない） |
| 初期配置 | **条件間で完全一致**（エピソードごとに `np.random.seed(seed*1000+index)`） |
| 変える要素 | 位置の出どころ（真値 / 推論-深度 / 推論-視線交点）、向きの出どころ（真値 / 固定） |
| 変えない要素 | 制御パラメータ、把持点補正、解放位置、指示文 |

## 結果

| 条件 | 位置 | 向き | タスク | 手順 |
|---|---|---|:-:|:-:|
| C0 | 真値 | 真値 | 10/20 | 45/60 |
| C0' | 真値 | 固定 | 8/20 | 44/60 |
| C1 | 推論（視線交点） | 真値 | 5/20 | 40/60 |
| C1d | 推論（深度読取） | 真値 | 0/20 | 15/60 |
| C2 | 推論（視線交点） | 固定 | 4/20 | 35/60 |

## 結論

**仮説は前半が正しく、後半が外れた。**

1. **正しかった**: AIへの置き換えコストは小さい（45/60 → 40/60、上限の89%）。
2. **外れた**: 向き合わせの寄与は**ほぼ消えていた**（C0 45 対 C0' 44）。
   以前 2/12 → 9/15 の差が出たのは**把持点補正を入れる前**であり、
   補正を入れた後は向きが合っていなくても掴めるようになっていた。
   > **∴ 過去に測った効果量を、条件が変わった後もそのまま使ってはいけない。**
3. **予想していなかった最大の発見**: 位置の求め方だけで 15/60 → 40/60 と変わった。
   **同定精度は両条件とも 53/60 で完全に同一**なので、交絡がない。

## 言えないこと

- C1 40 対 C2 35 の差（5手順）は 20エピソードでは**有意とは言えない**。
  向きの寄与が「ある」とは書けるが、「大きい」とは書けない。
- C0 45 対 C0' 44 の差1は**ゼロと区別できない**。「向き合わせは不要になった」とも書けない
  （測れていないだけ）。
- タスク成功率（10/20 など）は3手順すべての成功を要求するため、**手順成功率の3乗に近い形で効く**。
  タスク成功率の差だけを見て議論しない。
